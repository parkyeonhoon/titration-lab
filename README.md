# 중화 적정 가상 실험실

고등학교 '화학 반응의 세계' 산 염기 평형 단원의 중화 적정 탐구 수업용 가상 실험실입니다.
학생은 버튼으로 실험 조건을 골라 **실험 경로를 정하고**, 뷰렛으로 표준 용액을 넣으며 데이터를 기록합니다.
**실험 상태를 아는 AI 조교**가 정답 대신 질문으로 생각을 이끕니다.

## 진행 흐름

학생은 네 단계를 차례로 진행합니다. 위쪽 단계 표시줄과 회차 점(●●○)으로 진행 상황을 볼 수 있습니다.

1. **이론 학습**: 학습 목표, 핵심 개념 4가지(양적 관계, 중화점과 종말점, 강산·약산 적정 곡선, 지시약 선택), 영상, 실험 안내. "확인했어요"에 체크해야 다음으로 넘어갑니다.
2. **시약 선택 (시약장)**: 시료·표준 용액·지시약·측정 도구를 선반별로 고르고 고른 이유를 적습니다. 2회차부터는 지난 회차 조건이 미리 골라져 있어 그대로 반복하거나 바꿔 비교할 수 있습니다.
3. **실험**: 뷰렛으로 적정하고 값을 기록한 뒤 종말점을 표시하면 그 회차가 끝납니다. "이번 회차 처음부터"로 다시 하면 회차로 세지 않습니다.
4. **결과 정리**: 3회차를 모두 마치면 열립니다. 회차별 처음·종말점 눈금을 보고 넣은 부피와 농도를 계산해 적고, 평균 농도, 산의 세기 판단과 근거, 가장 믿을 만한 회차, 오차 원인을 제출합니다.

회차 수는 `config.js`의 `requiredTrials`, 영상은 `videos`에서 바꿉니다. 영상은 유튜브 영상 ID와 시작 시각(초)으로 넣으며, 수업 전에 직접 재생해 확인하세요.

## 주요 기능

| 기능 | 내용 |
|---|---|
| 시료 | 염산, 질산, 황산, 아세트산, 폼산, 옥살산, 수산화 나트륨 수용액, 암모니아수 |
| 지시약 | 메틸 오렌지, 메틸 레드, BTB, 페놀프탈레인, 티몰프탈레인 (변색 범위에 따라 색이 서서히 변함) |
| 뷰렛 조작 | 한 방울(0.05 mL), 0.1·0.5·1 mL, 꼭지 열기(누르고 있는 동안 1 mL/s), 다시 채우기 |
| 눈금 읽기 | 메니스커스 확대 보기. 연습 모드에서만 눈금 숫자 표시 |
| 측정 조건 | 이상적 / 현실적 (방울 크기 ±4 %, pH 미터 ±0.015, 처음 눈금 0~1.2 mL 무작위) |
| 데이터 | 학생이 "현재 값 기록"을 눌러 쌓음 → 적정 곡선, 지시약 변색 범위, 지난 회차 곡선(회색) 함께 표시 |
| 입자 보기 | 플라스크 속 HA, A⁻, H₃O⁺, OH⁻, Na⁺ 등의 양(mmol) 막대그래프 (연습 모드) |
| AI 조교 | 위쪽 "AI 조교" 버튼으로 어느 단계에서나 열림. 질문할 때 현재 단계와 실험 상태를 함께 보냄. 평가 모드에서는 꺼짐 |
| 기록 내려받기 | 회차별(다시 한 시도 포함) 경로·이유·데이터·종말점, 결과, AI 대화, 화면 이동과 모든 조작 기록을 JSON 파일로 저장 |

### 세 가지 모드

- **연습**: 시료와 농도를 알고 조건을 바꿔 가며 비교 (강산 vs 약산, 지시약 선택 등)
- **탐구**: 정체와 농도를 모르는 미지 산을 무작위로 배정, 세기와 농도를 밝힘
- **평가**: 학번 + 평가 코드로 학생마다 미지 산이 정해짐. AI 조교 사용 불가, 측정 조건 '현실적' 고정, 정답 피드백 없음

교사는 `teacher.html`에서 평가 코드와 학번을 넣어 학생별 배정 시료를 확인합니다.

## 폴더 구조

```
index.html      실험실 화면
teacher.html    교사용 평가 정답 확인
config.js       교사가 바꾸는 설정 (AI 서버 주소, 미지 산 목록 등)
style.css
js/chem.js      pH 계산 (전하 균형식을 이분법으로 풀이)
js/app.js       화면과 실험 진행
js/ai.js        AI 조교 채팅
worker/worker.js  AI 중계 서버 (Cloudflare Worker)
tests/          계산·중계 서버·화면 테스트
```

## 1. 실험실 공개하기 (GitHub Pages)

1. 이 저장소의 **Settings → Pages**로 갑니다.
2. **Source**를 `Deploy from a branch`, **Branch**를 `main` / `/ (root)`로 두고 저장합니다.
3. 1~2분 뒤 `https://<내아이디>.github.io/<저장소이름>/` 주소로 접속됩니다.

AI 조교 없이도 실험실은 바로 쓸 수 있습니다. 이때 AI 조교 탭에는 실험 상태를 복사해 다른 챗봇에 붙여 넣는 버튼이 나옵니다.

## 2. AI 조교 연결하기 (Cloudflare Worker)

GitHub Pages는 누구나 코드를 볼 수 있어서 API 키를 넣으면 안 됩니다. 그래서 키를 숨겨 주는 작은 중계 서버를 Cloudflare에 무료로 만듭니다.

1. [Cloudflare](https://dash.cloudflare.com)에 가입하고 로그인합니다.
2. **Workers & Pages → Create → Create Worker**를 누르고 이름을 정합니다 (예: `titration-ai`). **Deploy**를 누릅니다.
3. **Edit code**를 눌러 기존 코드를 모두 지우고 `worker/worker.js` 내용을 붙여 넣은 뒤 **Deploy**를 누릅니다.
4. Worker의 **Settings → Variables and Secrets**에서 다음 값을 추가합니다.

   | 이름 | 종류 | 값 |
   |---|---|---|
   | `API_KEY` | Secret | 내 API 키 (Anthropic 또는 OpenAI) |
   | `PROVIDER` | Text | `anthropic` 또는 `openai` |
   | `MODEL` | Text | (선택) 모델 이름. 비우면 `claude-haiku-5-5` / `gpt-4o-mini` |
   | `ALLOWED_ORIGIN` | Text | `https://<내아이디>.github.io` (실험실 주소만 허용) |
   | `CLASS_CODE` | Secret | (권장) 수업 코드. 학생은 AI 조교 탭에 이 코드를 넣어야 사용 가능 |

5. Worker 주소(예: `https://titration-ai.<계정>.workers.dev`)를 복사해 `config.js`의 `aiEndpoint`에 넣고 저장소에 커밋합니다.

### 비용과 안전

- 질문 1회당 답변은 최대 500토큰, 대화는 최근 12개 메시지까지만 보냅니다.
- `ALLOWED_ORIGIN`과 `CLASS_CODE`를 꼭 설정하세요. 설정하지 않으면 주소를 아는 누구나 내 API 키로 요청할 수 있습니다.
- API 제공사 콘솔에서 **월 사용 한도**를 걸어 두기를 권장합니다.

## AI 조교의 원칙

`worker/worker.js`의 `SYSTEM_PROMPT`에 있으며, 학생이 바꿀 수 없도록 서버 쪽에 둡니다.

- 농도, 중화점 부피, 이온화 상수, 미지 산의 정체를 직접 알려 주거나 계산해 주지 않음
- 학생의 실제 데이터와 선택을 짚으며 질문 1~2개로 돌려줌
- 단계(설계 → 적정 → 종말점 후 → 제출 후)에 맞춰 다른 질문
- AI는 **학생이 화면에서 보는 정보만** 받음. 미지 시료의 정체와 농도는 AI에게도 보내지 않음. pH 미터를 끈 실험에서는 pH 값도 보내지 않음

## 계산 모델과 한계

- pH는 전하 균형식을 풀어 구합니다 (25 °C, 활동도 보정 없음). 강산은 완전 이온화, Ka 값은 아세트산 1.8×10⁻⁵, 폼산 1.8×10⁻⁴, 옥살산 5.6×10⁻²·1.5×10⁻⁴, 황산 2단계 1.0×10⁻², 암모니아 Kb 1.8×10⁻⁵를 씁니다.
- '현실적' 측정 조건의 오차는 모델로 만든 것이며 실제 실험의 모든 오차(지시약 판단, 온도, 시약 오염 등)를 재현하지 않습니다. 실제 손 조작 경험은 시연 영상이나 실제 실험으로 보완하세요.
- 미지 시료와 평가 정답은 브라우저에서 계산되므로, 개발자 도구를 다룰 줄 아는 학생에게 완전히 숨길 수는 없습니다. 평가는 교실에서 감독하에 진행하고, `teacher.html` 주소는 학생에게 알려 주지 마세요.
